# SaaS Startup DevOps Pipeline

This repository contains the CI/CD pipeline, unit tests, containerization, and configuration files for the SaaS Product DevOps transformation.

## Repository Structure
- `.github/workflows/ci.yml`: GitHub Actions CI pipeline configuration.
- `app.py`: Core Flask web application.
- `test_app.py`: Pytest suite for automated testing.
- `requirements.txt`: Application dependencies.
- `Dockerfile`: Container image build specification.
